
# Movie Analysis

A Python project for exploring movie datasets,
analysing financial information and creating visualizations.

## Technologies

- Python
- Matplotlib
- Pytest
- TypedDict

## Installation

```bash
python -m venv .venv
python -m pip install -e ".[dev]"
```

## Execution

```bash
python -m movie_analysis.main
```

## Tests

```bash
python -m pytest
```

## Features

- Average movie rating
- Highest-rated movie
- Top movies by revenue
- Genre classification
- Estimated revenue minus production budget
- Revenue and budget visualizations
