
# Methodology

## Objective

Analyse a small collection of movies using Python
and statistical methods.

## Dataset

The dataset contains:

- Movie title
- Release year
- Genre
- Rating
- Runtime
- Production budget
- Gross revenue

## Data validation

The validation stage checks:

- Missing values
- Required columns
- Invalid ratings
- Negative financial values
- Duplicate titles

## Feature engineering

The preprocessing stage generates:

- Estimated profit
- ROI percentage
- Release decade

## Analysis

The project investigates:

- Average movie ratings
- Highest-rated movies
- Revenue rankings
- Genre distribution
- Budget and revenue relationships

## Limitations

The dataset is small and manually assembled.
Financial estimates do not represent net profit.
No causal relationship is inferred from the visualizations.
